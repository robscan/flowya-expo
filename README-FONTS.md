# Configuración de Fuentes Inter

## Descargar Fuentes Inter

Las fuentes Inter deben descargarse desde: https://github.com/rsms/inter/releases

Necesitas los siguientes archivos:
- Inter-Regular.ttf
- Inter-Medium.ttf
- Inter-SemiBold.ttf

## Instrucciones

1. Descarga las fuentes desde: https://github.com/rsms/inter/releases
2. Coloca los archivos en: `/assets/fonts/`
3. La estructura debe ser:
   ```
   assets/
     fonts/
       Inter-Regular.ttf
       Inter-Medium.ttf
       Inter-SemiBold.ttf
   ```

Las fuentes se cargarán automáticamente cuando inicies la app.
